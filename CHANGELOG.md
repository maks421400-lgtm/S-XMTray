# Changelog

## 0.5.2

- Fixed missing dialog backgrounds after changing language or theme.
- Added regression coverage for language/theme changes and background repainting.
- Updated the English README with English screenshots.

## 0.5.1

First public release as S-XMTray, previously developed as QuietTray.

- WF-1000XM5 noise control, battery, Speak-to-Chat and sidetone.
- EQ presets, five bands and Clear Bass.
- Optional global hotkeys, English/Russian and light/dark themes.
- Automatic reconnect and optional Windows startup.
- Fixed flickering in hotkey fields, the preset selector and EQ sliders.
